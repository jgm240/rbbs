rBBS

Dial in, log on, hang out. A bulletin board system in a single Python file.

Dial in What it does Run your own GitHub

Dial in

This page has a terminal. Pick the demo and a private copy of the whole BBS starts right here in your browser (Python, compiled to WebAssembly), or point the terminal at a live server.

Where to connect
Not connected

In the demo, log in as guest, register your own handle, or use sysop / sysop to try the sysop tools (force messages, polls, elections). Everything stays in this browser; the first dial-in downloads about 10 MB of Python and is quick afterwards. Chat bots keep the lobby company; multiplayer tables and the web terminal for other people need a live server.

What it does

Boards, mail and people

Threaded message boards with replies and a new-since-last-call scan, private mail, a oneliner wall, and calling-card profiles.

Chat

Rooms with topics and passwords, /roll /8ball /ignore /afk, mention highlights, and a button to page the sysop into a private room.

Games that need nothing installed

Chess against a built-in engine, a cave adventure, Hangman, Robots, Snake, Sudoku, Minesweeper and Solitaire. They run inside the call.

Multiplayer tables

Tic-Tac-Toe, Connect Four, Battleship, Reversi, Hangman and a Word Race against other callers, with a lobby.

Community

Polls, sysop elections that make deputy sysops, a weekly trivia question, a ten-question quiz, a caller of the month, last callers and 30 achievements.

Looks and sounds

Generated ASCII banners, rotating ANSI art for connect screens, rooms and boards, holiday screens, real modem speeds, ANSI music and CP437 for classic terminals.

Easy to run

One file, standard library only. A setup dialog like raspi-config, hot reload, timed messages, logs, and a web terminal over WebSocket.

Operator tools

hostbbs op kick, ban, mute, poll, election, and force: an urgent message on every caller's screen, however they are styled.

Connect screens

These are the art files the BBS rotates through, drawn from the .ans files in the repository. Each connect shows one of them, and on holidays an event screen follows.

Run your own

On a Linux box with systemd, one line sets it all up: it opens the setup dialog, then installs and starts a service.

curl -fsSL https://jgm240.github.io/rbbs/install.sh | sh

Or by hand (Python 3.9 or newer, nothing else):

git clone https://github.com/jgm240/rbbs.git
cd rbbs
./hostbbs            # the setup dialog: name, art, rooms, features...
./hostbbs run        # start it, then: telnet localhost 2323

Operate a running BBS from another terminal:

./hostbbs op who
./hostbbs op force "Back in five minutes"
./hostbbs op ban troll --ip

Put this terminal in front of your server

Turn on the web terminal in hostbbs.json, allow this page, and put TLS in front of it (browsers refuse plain ws:// from an https page, except for localhost):

"websocket": {"enabled": true, "host": "127.0.0.1", "port": 8080,
              "origins": ["https://jgm240.github.io"]}
# Caddy gets the certificate and proxies WebSockets by itself
bbs.example.com {
    reverse_proxy 127.0.0.1:8080
}

Then open this page with ?server=wss://bbs.example.com (use your own address). The terminal connects your browser straight to that server, which sees your address like any other caller's.

Telnet sends everything unencrypted, and so does a plain ws://. Passwords are only as private as the connection: use wss:// for anything public.
